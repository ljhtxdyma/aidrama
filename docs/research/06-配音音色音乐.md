# 06-配音音色音乐

> 原始调研笔记（2026-10-02，云端调研时整理）。正文结论已汇总进 docs/01-调研报告.md；这里保留细节与出处，标“未确认”的地方没有独立核实。

## 综述

截至 2026-10-02，中文真人短剧配音能用的开源模型分成三层。

**1. 主力配音（中文情绪 + 零样本克隆 + 可商用）**
- **IndexTTS-2.5**（B站，2026-08-10 开源）是首选。它把音色和情绪分开控制，情绪有三种输入：8 维情绪向量、情绪参考音频、情绪文本。新增拼音纠音和 `duration_factor`，RTF（生成耗时 ÷ 音频时长，越低越快）在 4090 上约 0.20。许可证是 bilibili 协议：月活 1 亿以下、年营收 10 亿元以下可免费商用。
- **IndexTTS-2** 仍值得保留。TTS-Audio-Suite 作者实听认为，迁移强烈情绪时 2.0 的音色保持比 2.5 好。
- **VoxCPM2**（OpenBMB，2026-04，Apache-2.0）：48kHz 输出、可设计音色、能用"(情绪描述)"控制克隆声，支持 9 种方言。
- **Qwen3-TTS**（2026-01-22，Apache-2.0）：VoiceDesign 是目前最好用的"给角色造声音"工具。但它的克隆模型（Base）不接受情绪指令。
- **Fun-CosyVoice3-0.5B**（2025-12，Apache）：方言最全，速度快。
- 2026 年新进入第一梯队的还有：MOSS-TTS v1.5 / MOSS-TTSD v1.0（Apache）、dots.tts（Apache，自报 Seed-zh SIM 81.0）、美团 LongCat-AudioDiT（MIT，自报 SIM 0.818）、OmniVoice（k2-fsa），以及腾讯 AuK（2026-09-09，MIT，指令式生成 + 编辑）。

**2. 质量顶尖但不能直接商用**
- Fish Audio S2 Pro：Research License，商用需另购授权。
- Higgs Audio v3：仅限非商用。
- F5-TTS：权重 CC-BY-NC。
- MMAudio：权重 CC-BY-NC。
- 微软已撤下 VibeVoice-TTS 代码。
- 没有找到 IndexTTS 3。
- MiniMax 的语音模型（Speech 2.x）仍只有 API；它开源的是 H3 音视频模型和 Music 3。

**3. 精确时长控制（对口型和剪辑的关键）**
- IndexTTS-2 论文里的"按 token 数精确控制时长"在开源版从未开放。2.5 只给了 `duration_factor`（0.5–2.0），只能整体拉伸长度。
- 真正能"按秒出音频"的开源模型有：
  - MOSS-TTS（`tokens=秒×12.5`）
  - OmniVoice（`duration=秒`）
  - LongCat（`duration=` 潜变量帧数）
  - AuK（`duration_seconds`）
- 所以短剧最稳的路线是**先出音频，再驱动视频**：先用 IndexTTS 把表演做足，再把音频喂给 InfiniteTalk / HuMo / LTX 的音频驱动，或 MiniMax H3 Ref2VA 的 `fully_copy`（每段 2–15 s，最多 3 段，总长 ≤15 s）。
- 如果先用 H3 / LTX / Wan3 生成了自带原生对白的视频，就用 Seed-VC v1 只换音色。时间轴不变，口型也不会坏。

**ComfyUI 0.38 的情况**：本地 clone 的源码 `comfyui_version.py` 显示 0.38.0（最新提交 2026-10-01）。原生支持 ACE-Step 1.5 / XL、MiniMax Music 3、YuE2、Stable Audio 3，以及 H3 / LTX 音视频。但原生**没有本地 TTS / 声音转换 / 音效 / ASR**，只有 ElevenLabs、Fish Audio、Seed Audio、HeyGen 这些 API 节点。所以 TTS 建议放在独立 uv 环境里，作为 HTTP 服务给 Python 编排脚本调用；需要拖节点时用 TTS-Audio-Suite 或 T8 的 IndexTTS-2.5 节点。

**音乐**：WildSongBench（YuE2 团队发布的基准）上开源歌曲质量排序为 YuE2 > MiniMax Music 3 ≈ ACE-Step 1.5。

**音效**：可商用的视频配音效首选仍是 HunyuanVideo-Foley。

**字幕**：台词是已知的，所以用 Qwen3-ForcedAligner 做强制对齐，效果最好。

## 可直接用的技巧与参数

**1. IndexTTS-2.5：常驻服务与情绪参数**（官方 API：`indextts/infer_v2_5.py`）
```python
# uv run serve_indextts.py   (在 index-tts 仓库根目录)
from indextts.infer_v2_5 import IndexTTS2
tts = IndexTTS2(cfg_path="checkpoints/config.yaml", model_dir="checkpoints",
                use_bf16=True, use_qwen_emo=True)  # use_emo_text 必须开 use_qwen_emo
# 向量顺序: [happy, angry, sad, afraid, disgusted, melancholic, surprised, calm]
tts.infer(spk_audio_prompt="chars/linwan_neutral.wav", text="你骗了我整整三年……", lang="ZH",
          emo_audio_prompt="chars/linwan_cry.wav", emo_alpha=0.8,      # 同一角色的哭腔样本，避免音色漂移
          output_path="out/s03_l12.wav",
          duration_factor=1.0, interval_silence=150, max_text_tokens_per_segment=120,
          # 生成参数（默认值）：do_sample=True, top_p=0.8, top_k=30, temperature=0.8,
          # num_beams=3, repetition_penalty=10.0, max_mel_tokens=1500
          )
tts.infer(spk_audio_prompt=..., text="快躲起来！他来了！", lang="ZH", use_emo_text=True,
          emo_text="极度惊恐，压低声音颤抖", emo_alpha=0.6, output_path=...)
```
常用情绪的向量起点。这些是经验值，不是官方值，需要试听；向量各维度之和建议 ≤1，用 `emo_alpha` 0.6–0.9 控制强度：

| 情绪 | 向量起点 / 做法 |
|---|---|
| 委屈哭腔 | `[0,0,0.65,0,0,0.3,0,0]`；最好配一段哭腔参考音频 |
| 暴怒 | `[0,0.9,0,0,0.1,0,0,0]` |
| 恐惧 | `[0,0,0.15,0.8,0,0,0.05,0]` |
| 冷笑 / 轻蔑 | `[0.15,0.15,0,0,0.6,0,0,0.1]`，再加 `emo_text="冷笑，轻蔑嘲讽"`；不够就交给 Step-Audio-EditX 的 coldness / arrogant + `[chuckle]` |
| 耳语 | IndexTTS 的向量里没有这个维度。用同一角色的耳语参考音频做 `emo_audio_prompt`，或用 Step-Audio-EditX `--edit-type style --edit-info whisper` / AuK 耳语转换 |

纠正多音字的写法：2.5 用 `<行|HANG2>`，2.0 直接写 `XING2`。

**2. 用 `duration_factor` 迭代逼近目标时长**（只用于后期重配；先出音频的流程用不到）
```python
import soundfile as sf, numpy as np
def trimmed_len(p, thr=0.01):
    y, sr = sf.read(p); y = y if y.ndim == 1 else y.mean(1)
    idx = np.where(np.abs(y) > thr)[0]
    return (idx[-1] - idx[0]) / sr
def fit(tts, target, **kw):
    f = 1.0
    for _ in range(3):
        tts.infer(duration_factor=f, output_path="tmp.wav", **kw)
        d = trimmed_len("tmp.wav")
        if abs(d - target) < 0.08: break
        f = min(2.0, max(0.5, f * target / d))
    return "tmp.wav"   # 剩余 ±5% 误差用 ffmpeg 补: -af "rubberband=tempo=X" 或 atempo
```

**6. Step-Audio-EditX 修音**（在原音频上做，音色保留）
```bash
python3 tts_infer.py --model-path SAE --tokenizer-path SAE_TOK \
  --prompt-text "原台词" --prompt-audio line.wav \
  --edit-type style --edit-info whisper --output-dir out
# 情绪: --edit-type emotion --edit-info angry|sad|fear|coldness|arrogant
# 副语言: --edit-type paralinguistic，并在 --generated-text 里写 "……[sigh]……"
# 其他: --edit-type denoise | vad | speed（speed 的 edit-info: faster/slower/more faster/more slower）
```

**7. Seed-VC：把 H3 / LTX 原生对白换成角色音色，口型不变**
```bash
python inference.py --source h3_line.wav --target chars/a_ref.wav --output out \
  --diffusion-steps 40 --length-adjust 1.0 --inference-cfg-rate 0.7 --f0-condition False --fp16 True
```
不要用 v2 的 `--convert-style true`，它的自回归部分会改时序。

**8. 喂给视频模型时的约束**：MiniMax H3 Ref2VA 的音频每段 2–15s，最多 3 段，总长 ≤15s，而且必须和图像或视频一起输入。提示词里写 `<Audio 1>: fully_copy`，音频会 1:1 作为成片音轨；写 `reference`，则只参考音色。TTS 的句子切分要按镜头控制在 15s 以内（来源：MiniMax-H3 README 与 skill 文档，本地副本）。

**9. 用强制对齐出字幕**（9:16 竖屏每行建议 ≤14 字，按标点切）


**10. 自动挑选最佳版本（QC）**
- 每句用 3–4 个 seed 各生成一版。
- 用 Qwen3-ASR-1.7B 回读算 CER，>3% 的直接淘汰。
- 剩下的用 FunASR `cam++` 说话人嵌入算与角色样本的余弦相似度，取最高。
- 可再用 SenseVoice 的情绪标签核对是否符合剧本标注。

**11. 混音（ffmpeg）**
```bash
# 对白：统一 48k，单句响度归一
ffmpeg -i line.wav -af "aresample=48000:resampler=soxr,loudnorm=I=-16:TP=-1.5:LRA=11" -ac 1 line48.wav
# BGM 在对白出现时自动压低（ducking），最后整体响度 -14 LUFS
ffmpeg -i bgm.wav -i dialog.wav -filter_complex \
 "[1:a]asplit=2[sc][dlg];[0:a]volume=-8dB[b];[b][sc]sidechaincompress=threshold=0.03:ratio=8:attack=15:release=350[duck];\
  [duck][dlg]amix=inputs=2:duration=longest:normalize=0,loudnorm=I=-14:TP=-1[out]" -map "[out]" -ar 48000 mix.wav
```
各模型输出采样率不一（IndexTTS 22.05k，Qwen3 / CosyVoice 24k，VoxCPM2 / dots 48k），全部先重采样到 48k 再混。

**12. ACE-Step 1.5 XL 的 BGM 参数**（ComfyUI 节点 `TextEncodeAceStepAudio1.5`）
- `duration` 设成镜头的精确秒数；`bpm` 和 `keyscale` 明确写。
- 纯器乐时 lyrics 写 `[Instrumental]`，`language` 选 zh。
- `cfg_scale` 2.0、`temperature` 0.85、`top_p` 0.9 用默认即可。
- 每个情绪段落出 4 版挑选。
- MiniMax Music 3 的 caption 按三段写：Global Metadata / Vocal Details / Arrangement。
- YuE2 的 Style 写"Chinese, female vocal, 72 BPM, piano, strings"；`mode` 选 `full`。

**13. 5090（Blackwell）环境**
- 每个模型用独立 uv 环境，PyTorch 要用 cu128 或更新的 wheel；IndexTTS 官方要求 CUDA Toolkit ≥12.8。
- flash-attn 2 对 sm_120 的预编译轮子不保证有，Qwen3-TTS / MOSS 退回 `sdpa` 即可。
- DeepSpeed 对 IndexTTS 不一定提速，官方建议两种都试。
- 128GB 内存足够让 MOSS 8B、Music 3、YuE2 这类大模型做 CPU offload。
