# 03-闭源前沿模型

> 原始调研笔记（2026-10-02，云端调研时整理）。正文结论已汇总进 docs/01-调研报告.md；这里保留细节与出处，标“未确认”的地方没有独立核实。

> 调研维度：第一梯队定义：截至2026-10闭源/商业视频生成模型第一梯队、开源差距、国内短剧团队用模情况、API价格与"API补镜"方案

## 结论
截至2026-10-02，商业视频生成的第一梯队已经整体换代。2025年的Veo 3、Sora 2、Kling 2.x 已不在头部，现在的头部模型同时具备原生音画同步、单次多镜头和多模态参考三项能力。按 Arena(原LMArena) 2026-09-21 快照与 Artificial Analysis(AA) 9月数据，第一梯队包括：Google Gemini Omni Flash / Omni 1.1 Flash（Arena 文生视频第1名，1516分）；字节 Seedance 2.0/2.5（即梦/火山引擎，国内短剧团队的事实标准）；阿里 Wan 3.0（单镜原生30秒，AA T2V v2.0 第1名1157，闭源）；MiniMax H3（Arena 图生视频第1名1495，AA 视频编辑第1名，权重开放）；BFL FLUX 3 Video；xAI Grok Imagine 1.5。紧随其后的是 HiDream-O1-Video、Meta Muse Video、HappyHorse 1.0。Kling 3.0/O3、Vidu Q3、Veo 3.1 已退到第二梯队，Arena 图生视频分数在1350-1400，比头部低约100-140 Elo。Kling 4.0 已于9-28内测、计划10月上线，尚无评测。Sora 2 的 App 已于2026-04-26关停、API 于09-24下线；Veo 4 并未发布，Google 改走 Gemini Omni 路线；Runway Gen-4.5 已跌到 Arena 第27名。

开源侧出现了质变。MiniMax H3 是第一个进入第一梯队的开放权重模型：33B，2026-08-03 放出权重，ComfyUI Day-0 原生支持。它在 Arena 文生视频排第8（1460，距第1名56 Elo），在 AA T2V v2.0 排第4（1139），比上一代开源模型高出300多 Elo（LTX-2 19B 1154、Wan2.2 1132、HunyuanVideo 1.5 1169）。LTX-2.5 在 AA 开源榜只有约950分。

但有一个关键前提：榜单分数来自官方托管的完整流程（Context-IR 提示词重写 → H3-Base 768p → Regenerate-2K），而开源包只含 H3-Base（原生短边768）。因此本地成片的分辨率和提示词理解都会低于榜单水平，差距目前没有公开量化。另一方面，基于 H3 后训练的 Utopai X（AA 第2名）、fal H3 Max（AA 图生视频第1名）、RunningHub 增强版说明 H3 底座的上限很高。

5090 上的社区实测：采用 pruned int8 加 NVFP4 文本编码器时，10s 864×480 约175秒（显存峰值26.9GB），15s 1344×768 约8.6分钟。NVIDIA Sol Engine 的两段式方案（H3 先出672×384草稿，再用 LTX-2.5 一步精修到1344×768）约40秒。

结论：
- **本地主力**：MiniMax H3（FL2VA + Ref2VA）。用 LLM 按官方 h3-prompt-writing 规范写结构化提示词来替代闭源的 Context-IR，再用 SoL-Refiner 或 SeedVR2 提升画质，可以达到"接近第一梯队"。
- **最低成本补到第一梯队**：只对精选镜头调用 MiniMax 官方 H3-Regenerate-2K（$0.05/s）或 H3 API（2K $0.13/s）。同源模型能保持人物和音色一致。
- **高难镜头**：大动作、多人群戏、30秒长镜头再用 Seedance 2.0 fast（促销价0.6元/s）、Seedance 2.5 或 Wan 3.0（720p ¥0.6/s）补镜。
- **合规注意**：Seedance 不允许直接上传真人人脸，需走虚拟人像素材库或真人认证流程；2026-04-01 起 AI 短剧须备案，07-01 起强制标注"AI生成"。

### MiniMax H3 开放权重（H3-Base FL2VA / Ref2VA）：本地第一梯队候选
- **category**：开源权重·本地主力候选
- **developer**：MiniMax
- **release_date**：2026-07-31 发布；2026-08-03 在 HuggingFace 开放权重，ComfyUI 同日原生合入（PR #15224）

- **quality_evidence**：Arena 文生视频第8名 1460（该条被标为 open，是开源模型最高名次；下一个开源模型 Kandinsky 5.0 Pro 只有1175）。AA 开源榜：T2V v2.0 中 H3 1139，第二名 LTX-2.5 Fast 仅950；图生视频开源第1名 1181。注意：这些榜单分数对应官方托管全流程，本地 H3-Base 原生只有768p，且缺少 Context-IR
- **strengths**：33B 稠密单流 Omni-Transformer，一次前向同时生成视频和立体声音频，口型天然同步；支持多种宽高比（含9:16），本地画布上限768×1344；4-15秒；中文对白稳定；单模型覆盖文生、首帧/尾帧/首尾帧生视频（FL2VA）和全参考生视频（Ref2VA）；ComfyUI 还有多帧参考（时间轴上最多4帧）、Fun ControlNet Union（姿态控制）、FastVideo FastH3 8步蒸馏、i2v 续写等原生模板；底座经后训练可超过 Seedance 2.5（Utopai X 为证）
- **weaknesses**：本地只有768p，2K 需 API；速度偏慢；提示词必须用官方结构化格式，Ref2VA 对措辞非常敏感；许可证有地域限制；下载体积大（pruned int8 组合42.5GB，全精度123.6GB）

## 推荐做法
- **stage**：第一梯队对标基准（定义成片验收标准） ；**primary**：Seedance 2.0/2.5（国内短剧事实标准），并以 Gemini Omni 1.1 Flash、Wan 3.0、MiniMax H3（官方2K）作为横向质检参照 ；**rationale**：三份榜单的头部高度重合：Arena（2026-09-21，约72万票）、AA T2V v2.0、AA I2V v1.0，头部分数集中在约1475-1516（Arena）。国内短剧公司普遍选用 Seedance 2.0（36氪调研）。建议用同一组短剧镜头（双人对白特写、情绪爆发、走位加运镜、多人同框）的盲评结果来定义"第一梯队"质检线，不只看单个模型名
- **stage**：本地主力：对白与表演镜头生成 ；**primary**：MiniMax H3 开放权重：FL2VA（文生/首帧/首尾帧）加 Ref2VA（多图、音色、动作参考），在 ComfyUI 原生节点下用 int8 convrot DiT 和 Qwen3-VL-32B NVFP4 文本编码器（文本编码器 offload 到128GB内存） ；**alternatives**：LTX-2.5 distilled：用于空镜、转场、B-roll 和快速预览；FastVideo FastH3 8步：用于批量抽卡和预览 ；**rationale**：H3 是唯一进入第一梯队的开放权重模型：Arena 文生视频第8名，与第1名相差56 Elo；托管版在图生视频排第1；比其他开源模型高约300 Elo。它一次前向同时生成画面和立体声，中文对白口型天然同步，支持9:16，有9图参考锁脸和音频参考锁音色。5090 上15秒768p约8.6分钟、10秒480p约3分钟，社区已验证可以跑通。中国大陆不在许可证排除地区，年营收低于2000万美元可免费商用，但须标注 "MiniMax H3"
- **stage**：提示词层（替代未开源的 H3-Context-IR） ；**primary**：由 LLM（本地 Qwen3 或云端大模型）加载 MiniMax 官方 h3-prompt-writing 技能（base-en.txt / ref-en.txt），把分镜剧本自动改写成 integrated_multimodal_description / overall_soundscape / non_diegetic_music（Ref2VA 用六段式）结构 ；**alternatives**：直接调用官方 H3-Context-IR API（输入 $0.90、输出 $3.60 每百万 token，单条约0.01-0.05美元） ；**rationale**：官方 README 明确说明 Context-IR 对最终质量"至关重要"，榜单分数也都是带 Context-IR 跑出来的。本地缺少这一层是开源版与榜单差距的主要来源之一；成本几乎可以忽略，必须补上
- **stage**：本地画质提升（768p 到1080p或2K） ；**primary**：NVIDIA Sol Engine 的 SoL-Refiner：H3 低分辨率草稿交给 LTX-2.5 一步精修（Efficient-Large-Model/SoL-Refiner-LTX-2.5-for-MiniMax-H3） ；**alternatives**：LTX-2.5 DFR 管线或 IC-LoRA pixel spatial upscaler；SeedVR2 3B/7B int8 视频超分（ComfyUI 原生模板） ；**rationale**：两段式方案在5090上端到端约40秒，比原生满分辨率还快。更重要的是所有精修都复用同一个草稿，人脸不会变成另一个人；原生重抽则会换脸。音频来自 H3 草稿，不进入第二阶段，口型不受影响
- **stage**：API补镜·首选（同源、性价比最高） ；**primary**：只对选中的本地 H3 768p 成片调用 MiniMax 官方 H3-Regenerate-2K（$0.05/秒），即官方 README 所述的"本地 H3-Base 加 API 模块"完整2K工作流；本地也搞不定的镜头直接用 H3 API（768p $0.08/秒，2K $0.13/秒） ；**alternatives**：fal MiniMax H3 Max（AA 图生视频第1名）；RunningHub H3 增强版（约0.1元/秒，多镜头叙事接近 Seedance 2.5，属厂商自测） ；**rationale**：同源模型补镜，人物、画风、音色和本地镜头最一致。2K 再生成依赖原始上下文"重画"细节，优于传统超分。1分钟成片全部做 2K 再生成也只需约3美元，远低于纯闭源方案
- **stage**：API补镜·高难镜头（大动作、多人群戏、超15秒长镜头、复杂特效） ；**primary**：Seedance 2.0 fast（720p 促销价0.6元/秒）。关键镜头再用 Seedance 2.5：先用 Draft 模式出480p预览，满意后复用同一任务 ID 渲染1080p ；**alternatives**：Wan 3.0（30秒单镜长镜头、文档转视频，720p ¥0.6/秒，阿里云百炼）；Kling 3.0/O3（打戏和人体动作，fal 带音频 $0.168/秒）；Gemini Omni 1.1 Flash（约 $0.10/秒，可多轮编辑）；Vidu Q3 Turbo（$0.035/秒起，适合漫剧） ；**rationale**：H3 单段上限15秒，长镜头和群戏是它的弱项。Seedance 在国内短剧中经过大量生产验证，ComfyUI 有官方 partner 节点，可以直接嵌进同一套工作流。注意：Seedance 不能直接上传真人人脸，需要用 Real Human 认证节点（api_seedance2_0_r2v_real_human）或虚拟人像素材库（asset:// ID）。第三方渠道（RunningHub、LibTV 等）常有2.9折到4折，比官方便宜很多
- **stage**：AI漫剧/动画风 ；**primary**：本地 H3（提示词首句写 2D-animated / 3D CG 风格，可加 minimaxh3_* 风格 embedding） ；**alternatives**：Seedance 2.5（什么值得买横评认为2D动画口碑更稳）；Vidu Q3（低价） ；**rationale**：漫剧对单秒成本敏感，行业成本已压到200-2500元/分钟；本地 H3 的边际成本几乎只有电费
- **stage**：排除项 ；**primary**：不把 Sora 2（已停服）、Veo 4（不存在）、Runway Gen-4.5（Arena 第27名）、Wan 2.2、HunyuanVideo 1.5、LTX-2 当作主力模型 ；**alternatives**：Wan 2.2 生态（Wan Animate 2、InfiniteTalk、VACE）只用于动作迁移、局部修复等辅助环节 ；**rationale**：它们与第一梯队相差约150-380 Elo，或已不可用，不满足"第一梯队成片"的目标

## 关键技术
- H3 提示词：除对白和画面内文字外一律写英文；结构固定为 integrated_multimodal_description / overall_soundscape / non_diegetic_music 三个字段。I2VA 首行必须原样写 "For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced."，后面空一行再写正文
- H3 中文对白写法：说话人用固定 ID (S1)/(S2)，跨镜头不变；台词写成 <d>[Chinese] 原文</d>，逐字保留、不翻译。画外音必须写 "says in an off-screen voiceover"，紧跟 "while his/her lips remain completely closed"。台词跨剪辑用 <scenetrans>，被片尾截断用 <cutoff>。首次出场时写明年龄、性别、音色、语速，有利于稳定音色
- H3 分镜写法：[Shot 1] 不加时间戳，开头先写风格（Live-action, cinematic / 2D-animated）；后续镜头写 "[Shot 2] At 00:03.500, the camera cuts to ..."，时间必须严格递增。运镜写成"类型 + 幅度 + 速度"，例如 "pushes in with small amplitude at slow speed"。画面内文字用英文双引号原样保留，例如 "营业中"。overall_soundscape 写1-4句，不写对白；non_diegetic_music 写1-3句器乐与速度，没有配乐就写 N/A
- H3 ComfyUI 参数（官方模板）：sampler 用 res_multistep，scheduler 用 simple；Ref2VA 参考多时改 beta 或 normal 往往更好。基础20步，或4步/8步 turbo LoRA（强度1.0）。帧数公式 max(5,round(sec*24)) 向上对齐到 17k+5；24fps。画布短边上限768，竖屏9:16 即 768×1344。ref_image_size 用 match 更快，用 max（最高2048短边）锁脸更强但更慢
- H3 Ref2VA：参考标签 <Picture N>/<Video N>/<Audio N> 必须与节点连接顺序一致；锁脸用清晰正脸图，各参考之间只轻微变化光照或角度；最多9图、3视频、3音频，合计不超过12个文件；音频参考不能单独作为唯一输入；对措辞非常敏感，要明确写出哪个参考控制镜头的哪一部分
- 先抽草稿再精修：固定 seed，先用 480p 或 672×384 加 turbo LoRA 低成本抽卡，选中的镜头再用 SoL-Refiner / LTX-2.5 精修或官方 Regenerate-2K。不要在高分辨率下重新抽，否则人物会换脸
- 5090 显存策略：DiT 用 pruned int8 convrot（约19.5GB）常驻；Qwen3-VL-32B NVFP4 文本编码器（14.6GB）编码完就 offload 到内存；PyTorch 用 cu130 版本；VAE 解码用 KJNodes 分块（chunk 16/8）避免爆显存；可选 Sol-Attn 稀疏注意力节点进一步加速
- Seedance 补镜：真人脸先通过 Real Human 认证节点，或上传私域素材库换取 asset:// ID；多镜头一致性靠 @ 引用同一张角色定妆图；Seedance 2.5 用 Draft 模式先出480p预览再出1080p，显著省钱；第三方渠道常有2.9折到4折
- 成本参照（每秒）：H3 API 768p $0.08、2K $0.13、Regenerate $0.05；Seedance 2.0 约1元（fast 促销0.6元）；Seedance 2.5 BytePlus 720p $0.231；Wan 3.0 720p ¥0.6；Kling 3.0 带音频 $0.168；Gemini Omni $0.10；Vidu Q3 Turbo $0.035；Grok 1.5 720p $0.14
- 合规：2026-04-01 起 AI 微短剧须备案后才能上线（按投资额与题材分级审核）；2026-07-01 起片头须标注"AI辅助制作"或"AI生成"；严禁未经授权使用真人形象。H3 许可证要求在产品中标注 "MiniMax H3"，且禁止用 H3 输出训练其他模型
