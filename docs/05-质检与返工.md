# 05 质检与返工

“第一梯队”首先要**没有硬伤**。平台审核会直接把明显的 AI 硬伤打回，观众看到也会立刻划走。
本文说明三件事：机器自动检查什么、人还要看什么、发现问题怎么用最小代价修好。

## 1. 平台硬伤清单（2026 年口径）

来源见 [research/01-行业现状与第一梯队标准](research/01-行业现状与第一梯队标准.md)。

| 类别 | 具体表现 | 本流水线的对应手段 |
|---|---|---|
| 建模崩坏、肢体缺陷 | 脸部融化，五官漂移，多手指，手和道具粘连 | 关键帧人工检查 → 抽多条 → 人工选条 |
| 穿模 | 人穿过桌椅，手穿过身体 | 同上；动作复杂的镜头改用 `flf2v` 或 Wan Animate 2 |
| 口型错位 | 对白和嘴型对不上，不说话的人在动嘴 | TTS 音轨驱动口型；提示词强制听者闭嘴；ASR 回读 |
| 机械配音 | 播音腔，没有情绪，读错多音字 | IndexTTS-2.5 情绪配音；读音标注 `银<行|HANG2>`；人工逐句听 |
| 静止、重复、掉帧 | 画面冻住，动作循环 | 冻帧检测；时长检查 |
| 双轨、错乱字幕 | 画面里自带文字，又叠一层字幕 | 提示词禁止画内文字；只烧录一层字幕 |
| 角色撞脸 | 和明星、网红或热门 AI 剧角色相似 | 设定阶段人工把关；红果跨剧人脸相似度超过 65% 会被驳回 |
| 未标识 | 没有 AI 标识 | 合成时自动加显式标识和元数据，见 [07-合规与授权](07-合规与授权.md) |

## 2. 机器自动检查了什么

每条视频生成后都会自动质检，结果写进 `project.yaml` 对应条目的 `qc` 字段，并显示在 `review.html` 上。

| 检查 | 方法 | 不合格条件 |
|---|---|---|
| 时长 | ffprobe | 比计划短 0.15 秒以上 |
| 音轨 | ffprobe | 没有音轨（H3 一定会出音频） |
| 黑场 | ffmpeg `blackdetect` | 出现 ≥0.4 秒的黑场 |
| 冻帧 | ffmpeg `freezedetect` | 出现 ≥1.5 秒画面完全不动 |
| 切镜时间 | ffmpeg 场景变化检测 | 多镜头段里，计划切点 ±0.35 秒内没有检测到硬切（检测到计划外的切点只给提示，不判不合格） |
| 对白 | Qwen3-ASR 识别本段对白窗口，与剧本拼接比对 | 字错率 > 15%（`audio.max_cer`）；常见原因是台词错、多了随机台词、吞字 |

自动选条规则：先选合格的条，再在合格的条里挑字错率最低的。全都不合格时，保留第 1 条，等你人工处理。
你人工 `pick` 过的段，之后补抽也不会被自动改选。

**机器看不出来的**：脸是否像本人、手和肢体是否正常、表演是否到位、听者有没有动嘴、服装道具是否连贯。这些都要靠人工审片。

## 3. 人工审片清单

打开 `episodes/<集>/review.html`，每段逐条看。建议的顺序（越往前越致命）：

1. **身份**：每个切点的脸和设定图是不是同一个人？中远景的脸有没有糊或变形？
2. **肢体和物体**：看手、道具、桌椅交界处，有没有多指、穿模、物体变形。
3. **口型**：说话人的口型是否跟台词同步？听的人有没有在动嘴？台词说完嘴有没有闭上？
4. **切镜**：切点是否落在台词之间？切过去的构图是否和关键帧一致？
5. **表演**：情绪是否对，眼神方向是否对（看向对话的人，而不是看镜头）？
6. **声音**：有没有多出来的人声、怪响、音乐（H3 原生音效偶尔会加戏）？对白音色是否和配音一致？
7. **连贯性**：和前后段比，服装、发型、道具位置、光线方向是否一致？

成片阶段，完整看一遍 `out/ep01.mp4`，再检查这些：

- 开头 3 秒有没有钩子，结尾有没有留悬念（这一条属于剧本，但要在这里最后确认）；
- 字幕是否被平台按钮遮挡（默认底边留 520 像素）；
- BGM 有没有盖住台词；
- 转场是否生硬；
- 右上角 AI 标识是否清晰。

## 4. 返工决策表

原则：**先判断问题出在哪一层，再到那一层去修。** 越往前修越便宜，但影响范围也越大。

| 现象 | 最可能的原因 | 首选做法 | 还不行 |
|---|---|---|---|
| 几条都“差一点” | 运气 | 补抽：`video --only <段> --takes 4` | 换 `quality` 预设；检查提示词 |
| 某个镜头的脸不像 | 关键帧就不像；或者参考图太多，注意力被分散 | 先看关键帧是否像，不像就重做关键帧 | 把该镜头拆成单独一段；减少同段角色数 |
| 中远景人脸糊 | H3 本地输出只有 768p 级，VAE 会让皮肤变软 | 中远景尽量不给脸部特写任务；改成近景 | 只对这一段用付费 Regenerate-2K 或 API 重做 |
| 听的人在动嘴 | 提示词约束不够；同段两人站得太近 | 检查提示词里有没有 “does not speak; the lips remain completely closed”；用 `.manual.txt` 加强描述 | 把听者镜头拆开，改用 FL2VA 单独生成（无对白） |
| 口型对不上 | 对白音轨太长，或者语速太快 | 检查配音时长；把长句拆成两句 | 改用 InfiniteTalk 兜底（SOP 第 11 节） |
| 出现剧本外的台词 | H3 原生音频“加戏” | 补抽；提示词里写明 “no other speech” | 用 `.manual.txt` 去掉可能引发说话的动作描述 |
| 切镜时间不对 | 段太长，镜头太多 | 补抽 | 减少每段镜头数（`video.max_cuts_per_segment: 3`），重新 `plan` |
| 动作穿模 | 动作太复杂 | 简化动作；改成 `flf2v`，用首尾帧限定动作 | Wan Animate 2，用真人表演驱动 |
| 服装、道具前后不一致 | 关键帧不一致；`outfits` 描述变了 | 统一 `outfits` 文字，重做受影响的关键帧 | 用 PS 修关键帧 |
| 配音读错字 | 多音字 | 读音标注：`<行|HANG2>` | 改写台词，避开这个字 |
| 配音情绪不对 | 情绪标签不合适 | 改 `emotion` 或写 `emo_vector` | 给该情绪配一段参考音频（`voice.emotion_refs`） |
| 超分后脸发假 | SeedVR2 7B 过度锐化 | `upscale.model: 3b` | `upscale.enabled: false` |

重抽的成本参考（quality 预设、10 秒段）：一条约 8–15 分钟。重做关键帧约 1 分钟一张。
所以只要怀疑问题出在关键帧，就先修关键帧。

## 5. 抽卡策略

- **默认每段 2 条**（`video.takes: 2`）。对白多、动作复杂的段，建议 3–4 条。
- **先快后精**：先用 `--preset balanced` 跑全集，确认调度和表演方向；再对选定的段用 `quality` 重抽（`--force`）。
- **固定种子可复现**：每条的种子由 集/段/条号 计算得出，记录在 `project.yaml` 里。同样的输入再跑一次，结果相同；`graphs/` 里保存了每次实际提交的完整工作流。
- 行业参考：Seedance 2.0 之前，精品团队的抽卡可用率约 20%（5 抽 1）。
  头部作品《民俗怪谈之纸妻》报告生成画面的直接使用率约 70%（用的是 Seedance 2.0）。
  本方案靠关键帧锚定和逐字台词约束提高可用率；实际比例请用你自己的数据统计（`review.html` 上能看到每段几条合格）。

## 6. 进阶：可以继续加的自动质检

调研中建议的完整质检分 L0–L5 六层（见 [research/10-剧本分镜与自动化框架](research/10-剧本分镜与自动化框架.md)）。
本流水线已经实现了 L0（技术）、L1（切点）、L2（对白 ASR）。以下几层需要额外的模型，暂未内置：

- **L3 身份**：用 InsightFace ArcFace，按每秒 2 帧抽帧，和角色设定图比对相似度。阈值建议从 0.40–0.50 开始标定。
- **L4 文字**：用 OCR 检查画面里有没有意外出现的文字。
- **L5 VLM 打分**：用 Qwen3-VL 看 3×3 帧网格，按手、脸、服饰、构图打分。

如果日产量很大、人工审片成了瓶颈，可以优先补 L3。在 `aidrama/qc.py` 里加一个函数，再在 `pipeline.py` 的第 C 遍质检里调用即可。
