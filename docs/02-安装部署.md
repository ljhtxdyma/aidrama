# 02 安装部署

本文说明怎样把整套流水线装到你的 RTX 5090 电脑上。推荐用一键脚本；想自己控制每一步，可以看第 4 节“手动安装”。

## 1. 硬件与系统要求

| 项 | 要求 | 说明 |
|---|---|---|
| 显卡 | RTX 5090 32GB | 默认参数按 32GB 调优；24GB 卡请用 `balanced`/`draft` 预设 |
| 驱动 | NVIDIA r580 或更新 | PyTorch cu130 和 comfy-kitchen 的预编译包都要求 r580+；Linux 必须用 `-open` 内核模块版驱动（Blackwell 架构要求） |
| 内存 | 128GB | ComfyUI 用内存暂存放不进显存的权重（H3 约 20GB DiT + 15GB 文本编码器 + 图像/超分模型） |
| 硬盘 | NVMe，剩余 ≥ 260GB | 模型 core+fast 约 160GB；音频模型、LLM、Python 环境和工程素材另需约 60–100GB |
| 系统 | Ubuntu 22.04/24.04（推荐）或 Windows 10/11 | Windows 上 PyTorch 锁页内存最多只能用物理内存的 40%，大模型换页更慢 |

## 2. 一键安装

### Windows

在仓库根目录打开 PowerShell（不需要管理员权限，winget 装软件时会弹出确认窗口）：

```powershell
powershell -ExecutionPolicy Bypass -File install\windows\install.ps1
```

### Linux

```bash
bash install/linux/install.sh
```

### 参数

| Windows | Linux | 默认值 | 含义 |
|---|---|---|---|
| `-StackDir D:\aidrama-stack` | `--stack ~/aidrama-stack` | 有 D 盘用 `D:\aidrama-stack`，否则用户目录 | ComfyUI、音频服务等安装位置 |
| `-Groups core,fast` | `--groups core,fast` | `core,fast` | 下载哪些模型组（见下表），`all` 为全部 |
| `-Source modelscope` | `--source modelscope` | `auto` | 模型来源：`auto`（HuggingFace → hf-mirror → ModelScope 依次尝试）、`huggingface`、`hf-mirror`、`modelscope` |
| `-PipMirror tuna` | `--pip-mirror tuna` | 空（官方 PyPI） | Python 包镜像：`tuna` 清华、`aliyun` 阿里云 |
| `-ComfyTag v0.38.2` | `--comfy-tag v0.38.2` | `v0.38.2` | ComfyUI 版本（低于 0.38 缺少必需节点） |
| `-SkipModels` / `-SkipAudio` / `-SkipLLM` | `--skip-models` / `--skip-audio` / `--skip-llm` | | 跳过某一步（例如模型已经手动下好） |

脚本可以重复运行：已完成的步骤会跳过，模型下载支持断点续传。

### 脚本做了什么

| 步骤 | 内容 |
|---|---|
| 0 | 检查显卡、驱动版本、磁盘剩余空间 |
| 1 | 安装 git、ffmpeg、[uv](https://docs.astral.sh/uv/)（Windows 用 winget，Linux 用 apt），用 uv 装好 Python 3.13/3.12/3.11 |
| 2 | 克隆 ComfyUI v0.38.2，建 `.venv`（Python 3.13），装 PyTorch cu130 和 ComfyUI 依赖，打印 CUDA 是否可用 |
| 3 | 给本仓库建 `.venv`（Python 3.12），安装 aidrama，生成命令入口 `aidrama.bat` / `aidrama.sh` |
| 4 | 下载思源黑体 SC（字幕烧录用）到 `fonts/` |
| 5 | 按 `configs/models.yaml` 下载 ComfyUI 模型到 `ComfyUI/models/<目录>/` |
| 6 | 克隆 IndexTTS 并 `uv sync`，下载 IndexTTS-2.5 权重；为 Qwen3-TTS/ASR 建独立环境并下载 3 个模型 |
| 7 | 安装 Ollama，拉取本地大模型，并建别名 `aidrama-llm` |
| 8 | 写入 `.stack.env`（记录各目录位置），下载 H3 官方提示词指南，跑一遍测试 |

### 模型分组

| 组 | 体积 | 内容 | 什么时候需要 |
|---|---|---|---|
| `core` | 约 129GB | H3 FL2VA + Ref2VA（int8）、Qwen3-VL-32B 文本编码器、H3 视频/音频 VAE、Qwen-Image-2512、Qwen-Image-Edit-2511、Qwen2.5-VL 文本编码器、SeedVR2 7B/3B、FILM、MiniMax Music 3 | 必装 |
| `fast` | 约 28GB | FastH3、H3 Turbo 4/8 步 LoRA、Qwen Lightning LoRA | `balanced` / `draft` 预设 |
| `lipsync` | 约 28GB | Wan2.1-I2V-14B 480p + InfiniteTalk + wav2vec2 中文 | 长独白、口型兜底 |
| `animate` | 约 23GB | Wan Animate 2（蒸馏 int8）+ CLIP Vision | 真人表演迁移（打戏、复杂走位） |
| `qwen21` | 约 34GB | Qwen-Image 2.1 及其提示词扩写模型 | **非商用许可**，只用于个人测试 |
| `control` | 约 4GB | H3 Fun ControlNet union、姿态检测 | 进阶：姿态/深度控制 |

只看清单不下载：`python scripts/download_models.py --groups all --list`。

## 3. 国内网络

| 问题 | 做法 |
|---|---|
| HuggingFace 打不开 | 安装时加 `-Source modelscope`（或 `hf-mirror`）。`download_models.py` 会自动把 `huggingface.co` 地址改写到 hf-mirror / ModelScope，失败时自动换下一个来源 |
| pip 慢 | 加 `-PipMirror tuna` 或 `aliyun`。脚本通过 `UV_DEFAULT_INDEX` 环境变量让 uv 使用镜像 |
| PyTorch 慢 | PyTorch 必须从 `download.pytorch.org/whl/cu130` 安装（PyPI 上的 Windows 版 torch 没有 CUDA）。速度慢时可以挂代理，或者先手动下载 wheel 再 `uv pip install <wheel 文件>` |
| GitHub 慢 | ComfyUI、IndexTTS 和字体都从 GitHub 获取；需要时请给 git 配代理：`git config --global http.proxy http://127.0.0.1:7890` |
| 开了 Clash 等系统代理 | aidrama 访问本机服务（ComfyUI、音频服务、Ollama）时会自动绕过代理；启动脚本里的健康检查也会绕过代理 |
| IndexTTS 首次运行要下载小模型 | 启动脚本检测到 huggingface.co 不通时，会自动设置 `HF_ENDPOINT=https://hf-mirror.com` |

需要登录才能下载的仓库，请设置环境变量 `HF_TOKEN` 或 `MODELSCOPE_TOKEN`。

## 4. 手动安装（可选）

一键脚本的每一步都可以手动完成，下面以 Linux 为例；Windows 把路径里的 `bin/python` 换成 `Scripts\python.exe` 即可。

```bash
STACK=~/aidrama-stack; REPO=$(pwd)

# ComfyUI
git clone --depth 1 --branch v0.38.2 https://github.com/comfyanonymous/ComfyUI.git $STACK/ComfyUI
uv venv --python 3.13 $STACK/ComfyUI/.venv
uv pip install --python $STACK/ComfyUI/.venv/bin/python torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu130
uv pip install --python $STACK/ComfyUI/.venv/bin/python -r $STACK/ComfyUI/requirements.txt

# aidrama
uv venv --python 3.12 $REPO/.venv
uv pip install --python $REPO/.venv/bin/python -e "$REPO[dev]"

# 模型
$REPO/.venv/bin/python scripts/download_models.py --comfy $STACK/ComfyUI --groups core,fast --source auto

# IndexTTS-2.5（对白配音）
git clone --depth 1 https://github.com/index-tts/index-tts.git $STACK/index-tts
(cd $STACK/index-tts && uv sync --extra webui)
uvx --from huggingface_hub hf download IndexTeam/IndexTTS-2.5 --local-dir $STACK/index-tts/checkpoints
#   或：uvx --from modelscope modelscope download --model IndexTeam/IndexTTS-2.5 --local_dir $STACK/index-tts/checkpoints

# Qwen3-TTS（音色设计）+ Qwen3-ASR（识别/对齐）
uv venv --python 3.11 $STACK/qwen-audio/.venv
Q=$STACK/qwen-audio/.venv/bin/python
uv pip install --python $Q "torch==2.8.*" "torchaudio==2.8.*" --index-url https://download.pytorch.org/whl/cu128
uv pip install --python $Q qwen-asr
uv pip install --python $Q --no-deps qwen-tts
uv pip install --python $Q "accelerate==1.12.0" librosa soundfile sox onnxruntime einops
for m in Qwen3-TTS-12Hz-1.7B-VoiceDesign Qwen3-ASR-1.7B Qwen3-ForcedAligner-0.6B; do
  uvx --from huggingface_hub hf download Qwen/$m --local-dir $STACK/qwen-audio/models/$m
done

# 记录路径，供 start_all 使用
printf "STACK_DIR=$STACK\nCOMFY_DIR=$STACK/ComfyUI\nINDEXTTS_DIR=$STACK/index-tts\nQWEN_AUDIO_DIR=$STACK/qwen-audio\n" > $REPO/.stack.env
```

为什么 Qwen 音频环境里要用 `--no-deps` 装 qwen-tts：`qwen-asr` 固定依赖 `transformers==4.57.6`，`qwen-tts` 固定依赖 `4.57.3`。两者只差补丁版本、接口一致，所以装前者的版本，后者跳过依赖检查。
如果你遇到兼容问题，可以给两者各建一个环境，分别用 `--engines voicedesign` 和 `--engines asr` 在 9002、9003 端口启动，再把 `aidrama.yaml` 里的 `audio.asr_url` 改成 9003。

## 5. 启动与停止

```powershell
powershell -ExecutionPolicy Bypass -File install\windows\start_all.ps1         # 每个服务一个窗口
powershell -ExecutionPolicy Bypass -File install\windows\start_all.ps1 -Only comfy
powershell -ExecutionPolicy Bypass -File install\windows\stop_all.ps1
```

```bash
bash install/linux/start_all.sh          # 后台运行，日志在 <stack>/logs/
bash install/linux/start_all.sh comfy    # 只启动 ComfyUI
bash install/linux/stop_all.sh
```

| 服务 | 地址 | 说明 |
|---|---|---|
| ComfyUI | http://127.0.0.1:8188 | 浏览器打开可以看到实时队列和预览；也可以把 `workflows/*.json` 拖进去手动跑 |
| IndexTTS-2.5 | http://127.0.0.1:9001 | 第一次请求时才加载模型（约 10–30 秒） |
| Qwen3-TTS / ASR | http://127.0.0.1:9002 | 同上 |
| Ollama | http://127.0.0.1:11434 | 安装后作为系统服务自动运行 |

ComfyUI 的启动参数：

- 默认：`--disable-fast-disk`（Windows 还会加 `--reserve-vram 1.5`）。
- 128GB 内存的机器上，fast-disk 模式会让每一步都重新读 SSD，社区实测会慢 1.5–2.5 倍，所以默认关掉。
- **不要加** `--highvram`、`--gpu-only`、`--novram`：它们会关闭 ComfyUI 的动态显存管理，H3 很容易显存不足。
- 想自定义参数：Windows 用 `-ComfyArgs "..."`；Linux 用环境变量 `COMFY_ARGS="..."`。

**显存轮转**：ComfyUI、音频模型和本地 LLM 共用一块显卡。流水线切换阶段前会自动让另外两方释放显存：

- ComfyUI：调用 `/free` 接口；
- 音频服务：调用 `/unload` 接口；
- Ollama：发送 `keep_alive=0`。

因此三个服务可以一直开着，不用手动关闭。

## 6. 大模型（LLM）怎么选

LLM 负责三件事：写剧集圣经、写分镜，以及把 H3 提示词扩写得更细。接口兼容 OpenAI 就能用。

| 方案 | 配置（写在工程目录 `aidrama.yaml` 或用环境变量） | 说明 |
|---|---|---|
| **Ollama 本地（默认）** | `llm.base_url: http://127.0.0.1:11434/v1`、`llm.model: aidrama-llm` | 安装脚本依次尝试拉取 Qwen3.8-27B GGUF（UD-Q5_K_XL）、Qwen3.6-27B、Qwen3.5-27B，拉到哪个就建别名 `aidrama-llm`。可以自动卸载、让出显存 |
| llama.cpp `llama-server` | `llm.base_url: http://127.0.0.1:8081/v1` | 速度更快（支持 MTP 投机解码），但不能自动卸载：建议放 CPU 跑，或者写剧本和生成画面分时段进行 |
| 云端（剧本质量最好） | `llm.base_url: https://api.deepseek.com/v1`、`llm.model: deepseek-chat`、`llm.api_key: env:DEEPSEEK_API_KEY` | 剧本创作对模型能力要求最高，云端大模型通常更好；一整部剧的 token 成本相对视频生成可以忽略 |

换模型：`ollama pull <模型名>`，然后 `ollama cp <模型名> aidrama-llm`。也可以直接在配置里写模型名。

## 7. 配置文件

- `configs/default.yaml`：全部参数及注释。**不要直接改**，升级时会被覆盖。
- `<工程目录>/aidrama.yaml`：只写需要覆盖的项，例如：

```yaml
video:
  preset: balanced
  takes: 3
llm:
  base_url: https://api.deepseek.com/v1
  model: deepseek-chat
  api_key: env:DEEPSEEK_API_KEY
post:
  aigc_producer: mystudio
```

- 环境变量（优先级最高）：`AIDRAMA_COMFY_URL`、`AIDRAMA_LLM_BASE_URL`、`AIDRAMA_LLM_MODEL`、`AIDRAMA_TTS_URL`、`AIDRAMA_DESIGN_URL`、`AIDRAMA_ASR_URL`、`AIDRAMA_MOCK=1`。

ComfyUI 不在本机时（例如另一台电脑），用 `AIDRAMA_COMFY_URL=http://<ip>:8188`。
注意，流水线通过 ComfyUI 的上传接口传参考图，所以跨机器也能用；但音频服务通过本地文件路径传数据，必须和 aidrama 在同一台机器上运行。

## 8. 验证安装

1. `aidrama doctor`：所有项打勾即可。`core` 模型组必须齐全，其他组按需下载。
2. `.venv` 里运行 `python -m pytest -q tests`：全部通过（不需要 GPU）。
3. 先用预演画质跑示例，确认链路通畅（几分钟）：
   ```bash
   ./aidrama.sh init-demo projects/demo && ./aidrama.sh run projects/demo ep01 --preset draft
   ```
4. 再用 `quality` 重跑视频阶段，检查画质：
   ```bash
   ./aidrama.sh video projects/demo ep01 --preset quality --force
   ./aidrama.sh upscale projects/demo ep01 --force
   ./aidrama.sh assemble projects/demo ep01
   ```

## 9. 升级

```bash
git pull                                   # 更新 aidrama
cd <stack>/ComfyUI && git fetch --tags && git checkout v0.38.x   # 升级 ComfyUI（先看 release notes）
uv pip install --python .venv/bin/python -r requirements.txt
```

升级 ComfyUI 后，跑一遍 `aidrama doctor`，再用 `scripts/comfy_validate.py` 校验工作流（必须用 ComfyUI 自己的 Python 运行）：

```bash
<stack>/ComfyUI/.venv/bin/python scripts/comfy_validate.py --comfy <stack>/ComfyUI "workflows/*.json"
```

不加 `--stub-models` 时，它还会报告缺哪些模型文件。
